# C10 — експериментальне порівняння

1. Відкрийте `/Realtime` у браузері, F12 → Network. Увімкніть Disable cache.
2. В іншій вкладці авторизуйтеся та змініть видання. Для кожного режиму зробіть однакову кількість змін (наприклад 5) за однаковий інтервал (наприклад 2 хвилини).
3. Перемикайте WebSocket / Long Polling / Adaptive Polling, записуйте реальні числа в `measurement-template.csv`.
4. У WebSocket враховуйте handshake і frames; у Long Polling — HTTP-відповіді і повторні запити; у Adaptive — періодичні HTTP-запити. Network може відображати стиснені байти — використовуйте однаковий спосіб вимірювання.
5. Середня затримка: різниця між часом запису `atUtc` у події та моментом її отримання клієнтом. Для порівняння використовуйте синхронізований годинник і кілька вимірювань.
6. Порівняйте накладні витрати і частоту запитів, навантаження на сервер та затримку; **не вигадуйте числа**.

Серверний feed in-memory, тільки для одного екземпляра застосунку. Для production і кількох реплік потрібен Redis pub/sub або інша спільна шина.
